# Department of Computer Science and Engineering

A simple responsive department website for the Federal Institute of Science and Technology (FISAT), with a custom department emblem and a student enquiry form demo.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

The enquiry form is a front-end sample; it does not send or store submissions. Faculty entries are illustrative and should be replaced with current official details before publication.
